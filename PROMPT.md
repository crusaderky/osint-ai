
This is a new project, Open Source Intelligence AI.
it is a fairly basic LLM client, with some challenges.

What is OSINT: verify financial and regulatory compliance of organizations and
individuals, using exclusively freely accessible data. This project is about building a
chatbot with web_search/web_fetch tools and a large library of skills.

There are 3 user personas in this project:

- A software engineer (me), with high tech skills and no functional skills. They set up
  the core software and produces an easy UX for the other two personas.
- A compliance officer, with very low tech skills and high functional skills.
  They prompt the chatbot to write new skills and test, update and refine existing skills.
  Once they finish a unit of work, they commit and push to github.
- A final user, with neither tech skills nor functional skills.
  They query the chatbot about an organizations or individual; this
  triggers a cascade of skill uses which culminates into an easily digestible report.
  They don't need git access.
