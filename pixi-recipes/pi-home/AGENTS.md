# OSINT AI

The project is `/workspace`. User-authored skills MUST live in
`/workspace/agents/<skill-name>/SKILL.md`, with supporting files beneath that
skill directory. Never create user skills under `$HOME`, `~/.pi`, `~/.agents`,
`.agents`, or `.pi/skills`. The user reviews these files with Windows tools
and commits them using a Windows Git GUI.

Read `/workspace/AGENTS.md` for project-specific guidance.
